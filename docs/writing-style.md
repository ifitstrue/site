# Writing Style

The site should sound like Andrew: clear, warm, specific, and lightly funny. The writing should feel polished without calling attention to the polish.

## Voice

- Prefer plain, complete sentences and concrete details.
- Use first person for Andrew's preferences, habits, and tested experience.
- Use direct instructions for the action a reader should take.
- Let personality come from useful specifics, understated humor, and occasional enthusiasm. Avoid generic promotional language.
- Be honest about uncertainty. Do not turn research, calculations, or assumptions into Andrew's personal experience.
- Use contractions naturally.
- Use exclamation points selectively.

## Punctuation and phrasing

- Never use em dashes. Use semicolons, commas, or parentheses instead.
- When naming ingredients inside a recipe step, use parentheses when it makes the instruction easier to scan.
- Prefer visible endpoints ("pea-sized crumbs" or "lighter and fluffier") over timing alone.
- Preserve Andrew's wording whenever it is already clear.

## Recipe structure

- Give each numbered step a short, direct title.
- Keep a simple action in the numbered step; do not create a substep for a single detail.
- Use lettered substeps when a stage contains multiple real actions.
- Use an aside only for context that is important but not itself an action.
- Keep recipe introductions useful and personal. Avoid generic recipe-blog descriptions.
- Distinguish between details Andrew has tested, details calculated from the recipe, and outside research.
